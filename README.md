# حضور AI – Hodoor AI

نظام ذكي تجريبي لإدارة الحضور المدرسي باستخدام اكتشاف الوجوه على الجهاز نفسه (MediaPipe Face Detector).

> **تنبيه:** هذه نسخة شخصية تجريبية (V1). **اكتشاف الوجه ليس تعرفاً على الهوية**؛ النظام لا يطابق الوجوه بأشخاص ولا ينشئ بصمات بيومترية.

## الأجهزة
| الجهاز | الدور |
|---|---|
| الآيباد | لوحة الإدارة: الطلاب، الصفوف والشعب، الإعدادات، نتائج التجارب |
| iPhone (Safari) | واجهة المعلم: الكاميرا الخلفية، اكتشاف الوجوه، قياس الأداء |

## التقنيات
React · TypeScript · Vite · Tailwind CSS · `@mediapipe/tasks-vision` · getUserMedia · IndexedDB (`idb`) · GitHub Pages.

## الخصوصية
- معالجة الفيديو محلياً بالكامل؛ لا يُرسل بث الكاميرا إلى أي خادم.
- ملفات MediaPipe (WASM والنماذج) مستضافة داخل الموقع نفسه – لا طلبات لخوادم خارجية أثناء التشغيل.
- البيانات تُحفظ في IndexedDB على الجهاز فقط، مع خيار حذف كامل.
- لا تُرفع صور أو بيانات تجارب إلى GitHub (انظر `.gitignore`).
- قفل لوحة الإدارة برمز PIN هو فصل في الواجهة وليس حماية أمنية؛ الموقع ثابت بلا خادم.
- أي مرحلة مستقبلية تتضمن تعرفاً بيومترياً على طلاب قاصرين تتطلب التصاريح والموافقات القانونية ووسيلة بديلة غير بيومترية.

## التشغيل محلياً
```bash
npm install
npm run dev      # يجهّز ملفات MediaPipe ثم يشغّل خادم التطوير
npm test         # اختبارات الوحدات
npm run build    # بناء نسخة النشر في dist/
```
> الكاميرا في Safari تتطلب HTTPS؛ للاختبار على الهاتف استخدم رابط GitHub Pages.

## النشر
عند كل دفع إلى `main` يبني GitHub Actions الموقع وينشره على GitHub Pages
(إعداد لمرة واحدة: Settings → Pages → Source: **GitHub Actions**).

## بنية المشروع
```
src/app        الهيكل والتوجيه (HashRouter)
src/i18n       العربية (افتراضية) والإنجليزية، RTL/LTR
src/components مكونات الواجهة المشتركة
src/db         طبقة IndexedDB (الطلاب، الصور، الصفوف، الإعدادات، التصدير/الاستيراد، الحذف الكامل)
src/lib        أدوات مساعدة (الرمز، تصغير الصور، المعرفات)
src/pages/admin صفحات لوحة الإدارة
scripts/       تجهيز ملفات MediaPipe
public/mediapipe/models  نماذج اكتشاف الوجه (short-range / full-range)
tests/         اختبارات Vitest
```

## خارطة الطريق
1. ✅ التخطيط وإعداد المستودع
2. ✅ لوحة الإدارة والطالب التجريبي (قفل PIN، الطلاب، الصورة المرجعية، الصفوف والشعب، تصدير/استيراد، حذف كامل)
3. ✅ واجهة المعلم: المسح المباشر (Live Face Scanning) بالكاميرا الخلفية
4. ✅ اكتشاف الوجوه (MediaPipe) وتتبعها والإطارات الملونة
5. قياس الأداء واختبارات المسافة والإضاءة
6. الاختبار على الآيباد وiPhone
7. النشر

## المسح المباشر (Live Face Scanning)
- بث مستمر من الكاميرا الخلفية (getUserMedia)، لا التقاط صور ولا تسجيل فيديو.
- كل إطار يُحلَّل في الذاكرة بـ MediaPipe Face Detector (نموذج full-range افتراضياً) ثم يُتخلّص منه.
- تتبع الوجوه أثناء حركة الهاتف بأرقام مؤقتة مجهولة (لا هوية، لا بصمة) حتى لا يُعدّ الوجه نفسه مرات.
- الألوان: أخضر = واضح، أصفر = يحتاج تحسين (بعيد/مهتز/إضاءة)، أحمر = ضعيف جداً أو مفقود.
- الكاميرا تتوقف فقط عند «إنهاء المسح» أو مغادرة الصفحة/إخفاء التطبيق.
- **اكتشاف الوجه ليس تحققاً من الهوية، ولا يُسجَّل حضور.**

## سياسة أمان المحتوى (CSP)
نسخة النشر تمنع المتصفح من الاتصال بأي خادم خارجي (`connect-src 'self'`).
السبب: مكتبة MediaPipe تحتوي مسجّل استخدام يحاول الإرسال إلى `odml.pa.googleapis.com` دون خيار لتعطيله؛ السياسة تحجبه.

## نقل البيانات بين الأجهزة
كل جهاز يحفظ بياناته محلياً. من «إعدادات النظام» صدّر ملف JSON واستورده في الجهاز الآخر.
الملف **لا يتضمن** الصور المرجعية ولا رمز الدخول، ولا يجب رفعه إلى GitHub (مستثنى في `.gitignore`).
